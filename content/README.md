# Agent 学习手册：基础、工程、评测和面试

## 导读：Agent 是给一个不可靠的零件，配上可靠的工程

大模型会写、会推理，但它按概率续写：每次结果可能不同，写出来的东西不保证是真的，还要花钱、花时间。它也碰不到外面的世界：查不了数据库，改不了文件。

**Agent** 是让模型在一个循环里反复“说要做什么 → 程序去做 → 把结果给它看”，直到把任务做完的系统。模型负责判断，循环、工具、权限、上下文这些模型以外的部分叫 **harness**。**Agent 工程**做的是把 harness 搭好，让这个不可靠的零件在里面可靠地干活；**Agent 评测**做的是在上线之前和之后，用数据回答“它到底好不好、有没有变好、能不能信”。

全书用一个真实项目当贯穿案例：oncall-agent-mvp，一个排查数据库问题的值班 Agent，带一套评测平台（代码不在本仓库，用到的运行数据导出在 `data/`）。讲到通用概念时，用它的真实运行数据落地；它没做的东西（比如 RAG、MCP），单独写小例子，并说明它为什么没做。基础部分用一个缩小版的“迷你值班现场”（`examples/mini_world.py`），例子全部跑一遍花费不到一块钱。

全书还反复拿三个现成的东西做参照：**Claude Code**（Anthropic 的命令行编程 Agent，功能最全的 harness 之一）、**pi**（一个开源的极简编程 Agent，故意只做最少的功能，源码适合对照着读）、**learn-claude-code**（一个开源教程，从一个循环开始，一章加一个机制，一步步搭出 Claude Code 的主要结构）。

五个部分的起点不同，每部分开头写了它面向谁、要先会什么。全书的共同起点是：会 Python，调过大模型的 API。统计（置信区间、配对比较、样本量）只在用到时交代，不推公式；具体框架和 SDK 的 API 也只在用到时交代。

### 第一部分 Agent 基础

写给会调大模型 API、但不清楚 Agent 和 harness 是什么的人，会 Python、调过一次聊天接口就能读。从一次模型调用出发，一步步长出一个 Agent：工具调用、循环、harness，最后拆开一个真实的 Coding Agent。读完能自己写出一个最小 Agent，讲清 Claude Code 这样的 harness 由哪些部分组成、各自解决什么问题。

| 单元 | 一句话核心 |
|---|---|
| [一 大模型：一个按概率续写文字的零件](01-llm-basics.md) | 每次调用都花钱花时间，同样的输入不保证同样的输出，写出来的不保证是真的 |
| [二 工具调用：模型只说要调什么，做事的是你的代码](02-tool-calling.md) | 模型只会输出“想调哪个函数、参数是什么”；执行、校验、把结果送回去，全是你的代码 |
| [三 Agent 循环：把工具调用放进一个 while](03-agent-loop.md) | 模型要工具就执行、结果追加回去、再问一次，直到它不再要工具；什么时候停、停下来交了什么，要你兜底 |
| [四 Harness：Agent = 模型 + Harness](04-harness.md) | 模型管判断，harness 管其余一切；机制挂在循环的固定位置上，管边界和验收，不替模型做决定 |
| [五 解剖一个 Coding Agent：从三十行循环到 Claude Code](05-coding-agent.md) | 编程 Agent 就是循环加 harness，再为长任务加上文件工具、计划、子 Agent、技能、压缩、记忆；每样都解决一个问题，也都有代价 |

### 怎么用这份手册

每个单元按同一个节奏组织：

1. **先看现象，再学原理**：能用代码复现的，先给可运行的代码和真实结果，再解释为什么。标着「深入一层（可跳过）」的部分第一遍可以跳过。
2. **动手**：例子在仓库的 `examples/`，文件名前缀是单元号。调模型的例子会把真实输出录在 `examples/output/`，加 `--replay` 不调模型直接看；读项目数据的例子直接跑，不花钱。
3. **带走**：每个单元末尾的「做项目时」是一张清单，做自己的项目时逐条对照。
4. **检验**：「面试常问」是原理的口述压缩版，读懂原理后再看。里面的“我实测”“我的项目”是示范说法，数字来自本书的实测和 oncall-agent-mvp，面试时换成你自己跑出来的数字和项目。最后合上文档做自测题，答案在 `answers.json`。

文中的模型行为都在 qwen-plus 上实测（2026-11），项目数据来自 oncall-agent-mvp 的评测平台。框架、基准、价格变化很快，涉及时效的地方注明了日期，以官方文档为准。
