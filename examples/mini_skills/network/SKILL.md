# 网络问题

## 症状
偶发超时、连接被重置，客户端和服务端两边的现象对不上。

## 必查
1. 必须有直接证据：丢包、重传、网络设备告警、同机房其他服务同时异常。
2. query_error_log 里的 "Aborted connection ... (Got an error reading communication packets)" 不是网络问题的证据：连接被拒、客户端超时断开都会产生它。
3. 数据库侧指标（连接数、CPU、慢查询、锁）都正常，只能说明“没查到数据库的问题”，不能说明“是网络问题”。

## 容易混淆
- 所有指标都正常时，最容易用排除法判成网络。先确认错误日志、慢日志都看过了。
- 查询工具本身超时，说明的是取证失败，不是数据库的网络有问题。

## 止血
切换到备用链路或其他可用区；联系网络团队提供丢包和重传数据。

## 结论
根因 NETWORK。证据必须是网络侧的直接证据；只有排除法时，结论应写 UNKNOWN 并说明还缺什么。
